For builders

Get your site into Pocket Web

You don't sign up with us. If your site is on the challenge's public list, Pocket Web reads it within a few hours. To work well:

  1. Let other sites load your files. Serve agent-manifest.json and your .network.json with Access-Control-Allow-Origin: *.
  2. Add 2–3 sample_queries to your network entry. Pocket Web shows them as examples and uses them to pick you.
  3. Write a one-line description a regular person understands: what you check or do, and for whom.
  4. Answer when another site calls you. If your agents use your page's own actions, publish them through the action bridge.

Pocket Web is an agent site too. Load it from yours: https://this-site/pocket_web · manifest · network · source

Everything Pocket Web knows about each listed site, including today's check, is public and machine-readable: directory.json.
